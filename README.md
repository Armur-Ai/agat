# agat

[![License: AGPL v3](https://img.shields.io/badge/License-AGPL_v3-blue.svg)](https://www.gnu.org/licenses/agpl-3.0)

**An Artificial Immune System for polymorphic, metamorphic, and AI-rewritten malware.**

agat recognizes self-mutating binaries the way a biological immune system
recognizes a pathogen despite antigenic variation: not by matching the surface,
but by **affinity** to an adaptive repertoire of detectors built over a
mutation-invariant **behavioral antigen**. The repertoire is generated by
**negative selection** against a model of benign "self," **matures via clonal
selection** to generalize across a family's variants, and is contextualized by a
**danger-signal layer** so that *different-from-self* is not naively equated with
*harmful*.

> This is **bio-inspired computing** — agat implements the *computational logic*
> of immune mechanisms. It is not a biological simulation, and this README never
> claims otherwise.

> This is defensive security research. agat analyzes samples; it does not generate them.

---

## The core idea

Polymorphism and metamorphism rewrite the **surface** of a program — bytes,
registers, instruction encodings, even the decryption algorithm. Classical
detection chases that surface: fingerprint the decryptor stub, normalize to a
canonical form, hash it, match the hash. It works until the surface changes in a
way the hash didn't anticipate — and an LLM coding agent can change the surface
*arbitrarily*, substituting whole algorithms while preserving behavior.

A biological immune system has the same problem and solves it differently. A
pathogen mutates its surface antigens constantly, yet the immune system still
recognizes it — because recognition is **graded affinity** against a **repertoire**
of detectors, not an exact match, and because that repertoire **adapts**: it is
shaped to ignore the body's own cells (negative selection) and it **matures** to
recognize variants it has never seen (clonal selection and affinity maturation).

agat applies that computational logic to binaries:

- It distills each sample into a **mutation-invariant behavioral antigen** — a
  signature derived from control-flow structure, opcode distribution, recovered
  plaintext, and semantic tells, all of which survive the surface rewrites that
  defeat byte- and hash-level matching.
- It learns a model of **self** (benign behavior) and generates a repertoire of
  **detectors** that cover the non-self (malicious) region while ignoring self.
- It recognizes unknown samples by **affinity**, and its detectors **mature** as
  it sees more variants of a family — so it catches variants it has **never seen**.
  Generalization, not memorization.

## The immune mapping

Every mechanism corresponds to a real algorithm running over agat's real feature
data. Foundational papers are cited in code headers and below.

| Immune mechanism | Algorithm | What agat does | Module |
|---|---|---|---|
| **Antigen presentation** | Behavioral feature projection | Turns a sample into a mutation-invariant signature vector + canonical-block token set; defines the affinity metric everything downstream uses | `agat-antigen` |
| **Self/non-self model** | Self-region modeling (variable radius) | Models the benign-behavior region of signature space from a benign corpus | `agat-immune::self_model` |
| **Negative selection** | NSA — Forrest et al. 1994; V-detector, Ji & Dasgupta 2004 | Generates candidate detectors, **censors** any that match self, keeps non-self detectors covering malicious space | `agat-immune::negative_selection`, `::detectors` |
| **Recognition** | Affinity matching | Matches an unknown antigen against the repertoire; a match = non-self = malicious; the matching detector identifies the family | `agat-immune::recognition` |
| **Clonal selection + affinity maturation** | CLONALG — de Castro & Von Zuben 2002 | Clones high-affinity detectors ∝ affinity, **hypermutates** ∝ 1/affinity, promotes the best to **memory cells** — generalizing across a family's variants | `agat-immune::clonal`, `::memory` |
| **Danger theory** | Dendritic Cell Algorithm — Greensmith & Aickelin 2005 | Fuses harm signals (PAMP / danger / safe) into a context score that cuts false positives and prioritizes genuinely dangerous samples | `agat-immune::danger` |

The thesis, stated plainly: **polymorphism rewrites the surface; agat detects on
the mutation-invariant behavioral antigen, the way the immune system recognizes
pathogens despite antigenic variation — and its detector repertoire matures via
clonal selection to catch variants it has never seen.**

## The behavioral pipeline (antigen presentation)

The immune core sits on top of a real, conventional analysis pipeline. This is
the layer that *presents the antigen* — it is preserved and reused, not replaced.

**Classical static analysis:**

- PE (Windows) and ELF (Linux) parsing, x86/x64 disassembly, CFG construction
- Entropy analysis, string extraction, import/export inspection
- Hashing: SHA-256, MD5, imphash

**Polymorphic-engine analysis** — surfaces a deep invariant:

- Decryptor-stub signal detection and bounded recovery of encrypted payloads
- Key recovery for common cipher schemes
- A **plaintext fingerprint** that is invariant across decryptor *implementations*
  — two samples that decrypt to the same payload share it even if they use
  different decryptors

**Metamorphic-engine analysis** — surfaces a structural invariant:

- Multi-pass canonical-form normalization (register/width canonicalization, NOP
  removal, instruction folding)
- Weisfeiler–Lehman hashing over normalized CFGs
- Per-block canonical hashes that feed the antigen's affinity metric

**AI-signal analysis** — surfaces semantic tells of LLM rewriting:

| Signal | Description |
|---|---|
| Stylometric features | Identifier verbosity, idiom density, opcode-distribution shape |
| Perplexity scoring | Decompiled pseudo-code scored against a bundled local code model via `llama.cpp` |
| Artifact scan | Refusal strings, tokenizer fragments, embedded prompts, model magic bytes |
| Cross-variant divergence | Same recovered plaintext + different control-flow = the algorithm-substitution signature of LLM rewriting |

In the immune framing these become **antigen features** and **danger signals**:
control-flow structure, opcode distribution, recovered plaintext, and stylometry
shape the antigen; entropy, suspicious imports, and AI artifacts feed the
dendritic-cell danger layer.

## Why an immune system, and not just better hashing

The honest answer is that hashing is a *binary* match: two samples either share a
fingerprint or they don't. An immune system recognizes by **continuous affinity**
over a learned, adaptive repertoire — which is exactly what's needed when an
adversary can rewrite the surface arbitrarily. agat measures its own
generalization: as the repertoire matures on a family's variants, its recognition
rate on **held-out** variants it has never seen goes **up**. That is the property
classical fingerprinting cannot have, and it is the property this project exists
to demonstrate.

Where the immune analogy is weaker than it looks — the per-sample (rather than
temporal) application of the dendritic-cell algorithm, the dependence of negative
selection on benign-corpus coverage, and the engineered affinity metric — is
documented honestly in [`docs/AIS_REBUILD_PLAN.md`](docs/AIS_REBUILD_PLAN.md §7),
not glossed over.

## Architecture

agat is a Cargo workspace of small, independently testable crates:

```
agat-core        traits, types, encrypted vault
agat-store       rusqlite persistence (samples, features, self-model, repertoire, memory cells)
agat-static      goblin parse, entropy, strings, imports        ┐
agat-disasm      iced-x86 + CFG                                  │  antigen
agat-poly        polymorphic recovery + plaintext fingerprint    │  presentation
agat-meta        metamorphic canonical form + WL hashing         │  (behavioral pipeline)
agat-ai          AI-signal detectors                             ┘
agat-antigen     antigen vector + affinity metric
agat-immune      self_model · negative_selection · detectors · recognition · clonal · memory · danger
agat-engine      scan facade: analyze → recognize → danger → one ScanResult (+ SARIF)
agat-cli         clap entry point
agat-tui         ratatui demo shell
```

Two crates are **reserved stubs with no code yet**: `agat-sandbox` (optional
dynamic analysis) and `agat-rewriter` (a planned companion that would produce
AI-rewritten variants of benign or research-known payloads, solely as fixtures
for agat to analyze). Until it exists, `tools/ai_gen.py` generates the
AI-rewrite fixtures.

See [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) for the full pipeline diagram.

## Usage

### Train once: model your benign "self" and learn families

Training needs the encrypted vault (it keeps the sample bytes), so these
commands ask for a vault password (or read `AGAT_VAULT_PASSWORD`).

```bash
# Ingest your benign baseline and any confirmed family samples
agat ingest ./benign/* ./family/*

# Run the behavioral (antigen-presentation) pipeline on everything
agat analyze

# Build the model of benign "self" (ids from `agat list`; with no ids,
# every sample tagged "benign" is used)
agat self build <benign-ids...>

# Generate the detector repertoire via negative selection
agat repertoire generate --seed 1

# Mature the repertoire on confirmed family variants (clonal selection)
agat mature <sample-id> --family <name>
```

### Scan: the operator front door

`scan` is stateless: files are analyzed in memory, nothing is written, and
no vault password is needed, so it runs unattended in CI or cron.

```bash
agat scan ./suspect.bin                    # human report
agat scan ./quarantine ./build/out --json  # files and dirs (recursive); JSON array
agat scan ./artifacts --sarif > agat.sarif # SARIF 2.1.0 for code scanning / SIEM
agat scan ./artifacts --fail-on malicious  # only a malicious verdict fails the job
agat scan ./new.bin --ingest               # also add it to the vault library
echo $?   # 0 clean · 2 review/suspicious · 3 malicious · 1 agat error
```

`agat recognize <sample-id>` gives the same report for a sample already in
the library. **How to interpret a result:**
[`docs/READING_OUTPUT.md`](docs/READING_OUTPUT.md).

### Configure (optional)

`~/.agat/config.toml` (or `--config PATH`); command-line flags override it.

```toml
[scan]
output = "json"          # text | json | sarif
fail_on = "suspicious"   # review | suspicious | malicious | never

[danger]
dangerous_at = 0.5       # danger score >= this => dangerous
safe_below = 0.33        # danger score <  this => safe

[allowlist]
sha256 = ["<64-hex sha256>"]   # always reported clean

[denylist]
sha256 = ["<64-hex sha256>"]   # always reported malicious (wins)
```

### Research views

```bash
agat show <sample-id> --poly --meta --ai   # per-analyzer detail
agat cluster        # exact CFG-fingerprint clustering
agat divergence     # cross-variant algorithm-substitution flagging
agat tui            # interactive demo shell
```

## Reproducible evidence

[`bench/`](bench/README.md) measures agat's claims, offline:

- `bench/generalize.sh`: train on 7 metamorphic variants, recognize a
  **held-out** 8th it never saw (generalization, not memorization).
- `bench/run.sh --benign-dir …`: **detection rate** over 8 held-out variants
  and the **false-positive rate** on held-out real benign binaries
  (220 Debian x86-64 ELFs: 8/8 detected, 0/110 FPs). CI-gateable.
- `bench/sweep.sh`: retrains under 32 perturbed affinity weightings to show
  the result is not a hand-tuned knife edge.

The family is synthetic (generated by `tools/*_gen.py`); the honest scope of
each number is spelled out in `bench/README.md`.

## Ethics & responsible use

agat is built for analysts, researchers, educators, and CTF authors. It is a
**defensive** tool.

- agat analyzes binaries. It does not weaponize them, exfiltrate them, or evade
  detection on behalf of them.
- The companion `agat-rewriter` tool is scoped to behavior-preserving stylistic
  rewrites of *benign or research-known* payloads, to produce demo samples for
  analysis. It refuses flagged-malicious inputs as a guardrail.
- Real in-the-wild samples used during research are not redistributed. The
  repository ships SHA-256 manifests; users fetch samples themselves from
  reputable sources under their own accounts.
- If you find a way to misuse agat or its components, please open an issue or
  contact the maintainers privately.
