# Glossary

Terms agat uses, in plain language. The immune analogy is explained in
[CONCEPTS.md](CONCEPTS.md).

**affinity** — How strongly two antigens match, in `[0, 1]`. A blend of
cosine similarity over the signature vector and Jaccard over block tokens.
Graded, not all-or-nothing — the reason agat generalizes.

**antigen** — A sample's mutation-invariant behavioral signature: the
features that survive repacking, register renaming, and rewriting. What agat
actually compares. See [the antigen diagram](assets/antigen.svg).

**clonal selection (CLONALG)** — The algorithm that builds family memory:
detectors that bind a confirmed variant are cloned and mutated toward it, and
the best becomes a memory cell.

**danger (axis)** — One of agat's two verdict axes: *does this carry harm
signals?* Fused from PAMP / danger / safe signals into a context (`safe`,
`ambiguous`, `dangerous`, `inconclusive`).

**DCA (Dendritic Cell Algorithm)** — The signal-fusion math behind the danger
axis.

**detector** — A point in antigen space with a radius. A sample it covers is
non-self. Generated by negative selection; a family-labelled one is a memory
cell.

**family** — A labelled malware family agat has been taught via `mature`.
A memory cell covers the family's neighborhood so new variants are
recognized.

**memory cell** — A long-lived, family-labelled detector: a covering ball
over a family's confirmed variants. Triggers a fast *secondary response* on a
new variant.

**metric space** — The geometry the signatures live in. Two models are only
comparable if they share one; agat pins it with the **antigen fingerprint**
and refuses packs from a different one.

**model** — A trained self-model + detector repertoire + memory pool, stored
in an agat home. Portable as a signed **pack**.

**negative selection (NSA)** — The algorithm that builds the repertoire:
generate random detectors, discard any that match self, keep the rest. Needs
no malware.

**non-self** — A sample outside the benign region (any detector binds it).
The recognition axis's core question.

**PAMP** — "Pathogen-associated molecular pattern": a definitive harm signal
(a recovered decryptor key, embedded LLM artifacts).

**pack (model pack)** — A trained model as one signed file (`agat.pack/v1`):
SHA-256 payload digest, optional Ed25519 signature, pinned metric. How you
deploy a model across a fleet.

**plaintext fingerprint** — A hash of the payload agat decrypted itself. Two
samples sharing it carry the same payload under different encryption.

**recognition (axis)** — One of agat's two verdict axes: *is this non-self,
and whose family?*

**recognize** — Present a sample's antigen to the model (recognition +
danger) and produce a verdict.

**repertoire** — The set of detectors (negative-selection + memory cells)
the model recognizes with.

**ScanResult** — The machine-readable verdict object (`agat.scan/v1`): both
axes, the fused severity, the model provenance. Has a published
[JSON Schema](schema/agat.scan.v1.json).

**secondary response** — Recognition via a memory cell — the fast "seen this
family before" path that catches unseen variants.

**self / self-model** — The region of antigen space occupied by *your*
benign software. agat's notion of "normal," learned from a benign corpus.

**severity** — The fused verdict: `clean` / `review` / `suspicious` /
`malicious`. Advice derived from the two axes; both axes are always reported
too.

**signature vector** — The fixed-dimensional numeric part of the antigen,
built from six weighted feature groups and L2-normalized.

**vault** — The AES-256-GCM-encrypted store of raw sample bytes in an agat
home. Only training/library commands open it (with a password); scanning
reads extracted features instead.
