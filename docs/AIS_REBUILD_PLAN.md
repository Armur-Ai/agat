# agat → Artificial Immune System: rebuild plan

**Status:** proposal for review. No mechanism code has been written yet.
**Scope:** replace agat's detection/classification *core* with a genuine
Artificial Immune System (AIS), reusing the existing behavioral pipeline as
the antigen-presentation layer.

> **Framing discipline (non-negotiable for the talk).** agat implements the
> *computational logic* of three immune mechanisms — negative selection, clonal
> selection, and the dendritic-cell / danger-theory algorithm. This is
> **bio-inspired computing**, not a biological simulation. Every component below
> corresponds to real, running code over agat's real feature data. Where an
> analogy is weaker than the others, it is called out explicitly in
> [§7](#7-where-the-analogy-is-weakest-honesty-ledger) so it can be presented
> honestly.

---

## 1. What agat is today

agat is a Rust Cargo workspace. The detection pipeline is a chain of
`Analyzer` implementations, each emitting a serializable `FeatureBundle`
(JSON features + optional binary artifacts) that is persisted to SQLite and
made available to downstream analyzers through `AnalysisContext.previous_features`.

```
ingest ──► Vault (AES-GCM encrypted raw bytes)
       └─► Store (SQLite: samples, features, artifacts)

analyze: static ─► disasm ─► poly ─► meta ─► ai     (dependency-ordered)
```

### 1.1 The behavioral pipeline (feature extraction)

| Crate | Emits | Mutation-invariance |
|---|---|---|
| `agat-static` | format/arch, entropy curve + high-entropy regions, ASCII/UTF-16 strings, SHA-256/MD5/imphash, sections, imports/exports | byte-level only |
| `agat-disasm` | recursive-descent disassembly, basic blocks, typed CFG edges, **opcode histogram**, function estimate | invariant to data encoding |
| `agat-poly` | decryptor signals, weighted `confidence`, recovered payload + **`plaintext_fingerprint`** (hash of recovered strings ≥10 chars) | **invariant to decryptor implementation** |
| `agat-meta` | canonicalized instructions, **per-block canonical hashes**, **`cfg_fingerprint`** (Weisfeiler–Lehman hash over the normalized CFG) | **invariant to register/width/NOP metamorphism** |
| `agat-ai` | artifact hits (refusal/ChatML/model-magic/...), stylometry (opcode diversity, block size, idiom hits), perplexity, weighted `combined_score` | semantic-level tells |

This pipeline is **good** and is exactly the right raw material for antigen
presentation. It already produces two genuinely mutation-invariant signatures
(`cfg_fingerprint` survives metamorphism; `plaintext_fingerprint` survives
polymorphism *and* algorithm substitution). **We keep all of it.**

### 1.2 The current "classifier" — what we are replacing

The actual matching/classification logic today is thin and non-adaptive:

| Mechanism | Implementation | Limitation |
|---|---|---|
| `poly.confidence` | fixed weighted sum of signal weights, capped at 0.95, threshold 0.5 | hand-tuned constants; no learning |
| `ai.combined_score` | fixed weighted sum of three sub-scores, threshold 0.5 | hand-tuned constants; no learning |
| `agat cluster` | bucket samples by **exact** `cfg_fingerprint` equality | binary match/no-match; cannot recognize an unseen variant whose hash differs by one block |
| `agat divergence` | group by **exact** `plaintext_fingerprint`, flag CFG-hash minorities | exact-hash grouping; no graded affinity |
| `meta show` cluster | exact `cfg_fingerprint` equality | same |

**The core weakness:** classification is *exact-hash bucketing + fixed
thresholds*. There is no model of "normal," no repertoire, no adaptation, and —
critically — **no ability to recognize a variant it has never seen** unless that
variant hashes bit-identically to a known one. That is precisely the gap an
immune system closes: graded affinity recognition over a learned, maturing
detector repertoire.

## 2. The core thesis (to state plainly in the talk and README)

> Polymorphism and metamorphism rewrite the **surface** of a program — bytes,
> registers, instruction encodings, even the decryption algorithm. agat does not
> match on the surface. It builds a **mutation-invariant behavioral antigen** from
> a sample and recognizes it the way the immune system recognizes a pathogen
> despite antigenic variation: by **affinity** to a repertoire of detectors. That
> repertoire is generated by **negative selection** against a model of benign
> "self," **matures via clonal selection** to generalize across a family's variant
> neighborhood, and is contextualized by a **danger-signal layer** so that
> "different from self" is not naively equated with "harmful." Because affinity is
> continuous, agat recognizes variants it has **never seen** — generalization, not
> memorization.

## 3. Target architecture — the immune pipeline

Each stage names the algorithm it implements and the founding paper it cites.

```
                 ┌─────────────────────────────────────────────┐
                 │  EXISTING BEHAVIORAL PIPELINE (kept as-is)   │
                 │  static → disasm → poly → meta → ai          │
                 └───────────────────────┬─────────────────────┘
                                         │ FeatureBundles
                                         ▼
   ┌───────────────────────────────────────────────────────────────────┐
   │ 1. ANTIGEN PRESENTATION            (agat-antigen)                   │
   │    FeatureBundles → mutation-invariant antigen:                    │
   │      • real-valued signature vector  s ∈ ℝⁿ  (normalized)         │
   │      • canonical-block token set     B  (from agat-meta)          │
   │    + affinity(a,b): weighted scalar distance ⊕ Jaccard(B_a,B_b)   │
   └───────────────────────────────┬───────────────────────────────────┘
                                   │ antigen
        ┌──────────────────────────┼───────────────────────────────────┐

 │ 2. SELF-MODEL│    │ 4. RECOGNITION           │        │ 6. DANGER LAYER (DCA)  │
```

### Stage 1 — Antigen presentation · `agat-antigen` (NEW)
- Consume the persisted `FeatureBundle`s and project them into:
  - **Signature vector** `s ∈ ℝⁿ`: normalized opcode-frequency distribution
    (from `disasm.opcode_histogram`), CFG shape scalars (block/edge counts,
    mean block size, cyclomatic proxy `edges − blocks + 2`), entropy summary
    (overall, region count, boundary delta), stylometry scalars
    (opcode diversity, underscore density, mean/long string counts), and a
    coarse import/section profile.
  - **Canonical-block token set** `B`: the `block_fingerprints` already produced
    by `agat-meta` (register/width/NOP-invariant block hashes).
- **Affinity / distance** (explicit + configurable, per the brief):
  `affinity(a,b) = α·cos(s_a, s_b) + β·Jaccard(B_a, B_b)`, with a configurable
  blend and an L2 option. The complement `distance = 1 − affinity` is the metric
  NSA/CLONALG/DCA operate in.
- **Why this is honest and necessary:** NSA, CLONALG, and DCA all require a
  *metric space*. The existing fingerprints are hashes (no metric — match is
  all-or-nothing). The antigen vector turns the real behavioral features into a
  genuine metric in which **variants of one family are close and different
  families are far**. Opcode distribution and block-token Jaccard are
  metamorphism-tolerant (register renaming doesn't move them) but move sharply
  under algorithm substitution — which is the behavior we *want* the geometry to
  reflect.
- **Acceptance test:** mean intra-family affinity > mean inter-family affinity by
  a clear margin on the `tools/meta_gen.py` + `tools/ai_gen.py` corpus.

### Stage 2 — Self-model · `agat-immune::self_model` (NEW)
- Build a model of "self" = the set of antigen vectors from a **benign** corpus
  (tagged via existing `SampleMetadata.tags`/`family`, or an explicit
  `agat self build --benign <ids>`).
- Representation: the self antigen set plus a per-sample **self-radius** (the
  distance to its k-th nearest self neighbor), giving a variable-radius
  description of the benign region (the V-detector "self" notion).
- Persisted in a new `self_model` store table.
- **Acceptance test:** benign samples fall inside the self region; the
  `meta_gen`/`ai_gen` decryptors fall outside it.

### Stage 3 — Negative selection · `agat-immune::{negative_selection, detectors}` (NEW)
- Implement real **NSA** (Forrest, Perelson, Allen & Cherukuri, 1994) in its
  real-valued **V-detector** form (Ji & Dasgupta, 2004): sample candidate
  detector centers in signature space; **censor** any candidate whose distance to
  the nearest self point is below the affinity threshold; keep survivors as
  detectors with a radius extending to (just short of) the nearest self point.
  Stop on coverage estimate or a candidate budget.
- Configurable: affinity/distance function, self-tolerance threshold, target
  coverage, max detectors.
- Persisted in a `detectors` store table (center vector, radius, provenance,
  generation, affinity stats, optional family label once matured).
- **Acceptance tests:** (a) no surviving detector matches any self sample;
  (b) detectors collectively cover held-out non-self samples; (c) raising
  self-tolerance monotonically shrinks the repertoire.

### Stage 4 — Recognition · `agat-immune::recognition` (NEW)
- Match an unknown sample's antigen against the repertoire: a detector
  **recognizes** when `affinity ≥ 1 − detector.radius` (i.e. the antigen lies
  within the detector's non-self ball). Emit the matching detector(s), their
  affinities, and — if a matched detector carries a family label from clonal
  maturation — the identified **family**.
- Output is immune-framed: antigen summary, best-matching detector, affinity,
  whether the match came from a **memory cell** (secondary response).
- **Acceptance test:** known-malicious antigens are recognized; self antigens are
  not (false-positive rate measured against the self corpus).

### Stage 5 — Clonal selection + affinity maturation · `agat-immune::{clonal, memory}` (NEW)
- Implement real **CLONALG** (de Castro & Von Zuben, 2002). On a confirmed family
  variant (`agat mature <id>` / ingest of a labelled variant):
  1. select the highest-affinity detectors for the antigen;
  2. **clone** them in number proportional to affinity;
  3. **hypermutate** each clone with rate **inversely** proportional to its
     affinity (high-affinity clones explore locally, low-affinity clones explore
     widely);
  4. select the best matured clones, **retire** weak/old detectors;
  5. **promote** top detectors to **memory cells** (a persistent, fast-path
     repertoire) labelled with the family.
- Persisted: matured detectors + `memory_cells` table.
- **This is the headline result.** The demo trains memory cells on variants
  1..k of a family, **holds out** variant k+1, and shows a memory cell recognizes
  the held-out variant with affinity above threshold even though **no exact hash
  matches**. Generalization is measurable: recognition rate on held-out variants
  must rise as more variants are matured in.
- **Acceptance test:** held-out-variant recognition rate strictly increases with
  the number of matured variants; a never-matured *different* family is **not**
  recognized by that family's memory cells (no overgeneralization).

### Stage 6 — Danger-signal layer (DCA) · `agat-immune::danger` (NEW)
- Implement the **Dendritic Cell Algorithm** (Greensmith, Aickelin & Cayzer,
  2005) signal model. Map agat's real harm signals to DCA signal categories:
  - **PAMP** (definitive pathogen-associated pattern): `poly` decryptor-loop
    *with recovered key*; `ai` refusal-string / ChatML / model-magic artifacts.
  - **Danger**: high-entropy regions, entropy boundary, W+X / RWX sections,
    suspicious imports (e.g. `VirtualAlloc`+`VirtualProtect`, `ptrace`,
    `mprotect`+exec), cross-sample CFG divergence within a plaintext family.
  - **Safe**: low overall entropy, benign import profile, nominal stylometry.
- Apply the DCA signal-fusion transform to produce per-sample **CSM / semi-mature
  / mature** context and an MCAV-style **danger score**, then fuse with
  recognition: a non-self recognition that carries no danger context is
  **down-weighted** (fewer false positives), while PAMP-backed recognitions are
  **prioritized**.
- **Acceptance test:** a non-self-but-benign sample (different-from-self,
  zero harm signals) gets a low danger score; a decryptor-with-key + RWX +
  artifact sample gets a high one; fusing danger reduces the self-corpus
  false-positive rate vs. recognition alone.

### Stage 7 — CLI / TUI wiring (MODIFY)
- Keep existing commands working: `ingest`, `list`, `analyze`, `show`,
  `cluster`, `divergence`, `tui`.
- Add immune commands:
  - `agat self build` — construct/refresh the self-model.
  - `agat repertoire generate` — run negative selection; `repertoire list`.
  - `agat recognize <id>` — recognition + danger; immune-framed report.
  - `agat mature <id>` — clonal selection on a confirmed variant.
- Add immune-framed output: antigen summary, matched detector/family, affinity,
  danger score, and whether a memory cell formed (per the brief).
- `poly`/`ai` keep their existing scores but are now **inputs to the danger
  layer**, not the final verdict.

### Stage 8 — Docs + reproducible demo (NEW)
- `README.md` rewritten to the AIS framing (**done first**, per request).
- `docs/ARCHITECTURE.md` with the pipeline diagram + module map.
- `bench/` (or `examples/`) reproducible benchmark: feed several polymorphic
  variants of a family, mature the repertoire, then detect a **held-out**
  variant — proving generalization. Extend `tools/*_gen.py` to emit an N-variant
  family with a designated hold-out.

## 7. Where the analogy is weakest (honesty ledger)

Flagged so the talk can address these head-on rather than overclaim.

1. **DCA temporality.** Canonical DCA processes a *temporal stream* of antigen,
   with a population of dendritic cells each sampling signals over time before
   reaching maturity. agat is a static, per-sample analyzer. We implement the DCA
   **signal categorization and context-fusion math faithfully**, but apply it over
   each sample's *internal* signal set rather than a true antigen-over-time
   stream. Honest framing: "DCA-style signal fusion," not "a running dendritic
   cell population." (We *could* stream over a sample's regions/functions to
   restore some temporality — noted as an option, not promised.)

2. **Negative-selection coverage vs. self-corpus size.** NSA's theoretical
   non-self coverage depends on the density/representativeness of the self
   sample. agat's benign corpus will be small, so NSA is honestly a
   **complementary anomaly layer** (with measured, not guaranteed, coverage),
   not a proof of complete malicious-space coverage. We will report coverage
   numbers, not assert completeness.

3. **Engineered affinity function.** The antigen affinity blend
   (cosine over the signature vector ⊕ Jaccard over block tokens, weighted α/β) is
   a **designed metric**, not one learned or derived from biology. It is a genuine
   metric and we justify each term, but the weights are a modeling choice and will
   be presented as such (with a sensitivity check in the bench).

4. **"Self" is benign-behavior, not literal host tissue.** The self/non-self
   discrimination is over *behavioral signature space*, which is the correct
   computational analogue — but worth stating plainly so no one hears a claim
   about modeling an actual organism.

None of these break the core mechanisms; they are scoping statements that keep
the work scientifically honest.

## 9. Design decisions (locked)

1. **Crate split:** `agat-antigen` (signature vector + affinity) **+** `agat-immune`
   (modules `self_model`, `negative_selection`, `detectors`, `recognition`,
   `clonal`, `memory`, `danger`). ✅
2. **Self corpus:** the bench **synthesizes benign ELFs** (ordinary
   compute/loop programs, no decryptor) alongside the `*_gen.py` decryptors to
   populate "self" — fully reproducible, no external data required. The self
   corpus stays **pluggable** (tag/CLI) so a real benign set can be substituted. ✅
3. **Verdict semantics:** **two axes** — recognition affinity (non-self / family)
   and danger context (harm) reported separately, with an optional fused score for
   the demo. Keeps "different from self" distinct from "dangerous." ✅
